## Overview

LambShock helps you move from an empty workspace to a working setup quickly. This starter kit shows the shortest path through prerequisites, setup, first project creation, verification, and a basic workflow you can repeat and customize.

<Callout kind="info">

This page is a starter kit template. Replace the sample names, endpoints, and workflow steps with details from your own product.

</Callout>

## Prerequisites

Before you begin, make sure you have the basics ready:

- An account or access to your LambShock workspace
- A recent version of Node.js or another supported runtime
- Permission to create projects and run test workflows
- A terminal and text editor available locally

## Your first workflow

The following example shows a minimal workflow that sends a request, checks the response, and writes a simple success message. Use it as a template for your own process.

```javascript
import axios from "axios";

async function runWorkflow() {
  const response = await axios.post("https://api.example.com/workflows/run", {
    projectId: "proj_1024",
    source: "quickstart",
    dryRun: false
  });

  if (response.status === 200) {
    console.log("Workflow completed successfully");
  } else {
    console.error("Workflow failed", response.status);
  }
}

runWorkflow().catch((error) => {
  console.error("Unexpected error", error.message);
});
```

## Verification

Use the checklist below to confirm that your setup is working as expected.

1. Your project file exists and loads without syntax errors.
2. The workflow request returns a successful HTTP response.
3. Your console shows the confirmation message.
4. The environment values resolve correctly in your shell.
5. You can repeat the run without changing the setup.

<Callout kind="tip">

If the request fails, check the endpoint URL, project identifier, and local environment values before you retry.

</Callout>
