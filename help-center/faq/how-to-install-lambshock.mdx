title: How do I install LambShock?
description: Installation instructions for LambShock.
---

## Overview

LambShock is installed via npm. Node.js 16+ is required.

## Steps

1. Open your terminal.
2. Run:

    ```bash
    npm install lambshock
    ```

3. Import LambShock in your project:

    ```js
    import { LambShock } from 'lambshock';
    ```

4. You're ready to use LambShock components.
