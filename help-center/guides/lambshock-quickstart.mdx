## Create a Simple Page

<Steps>
  <Step title="Install LambShock">
    ````bash
    npm install lambshock
    ````
  </Step>
  <Step title="Add a Component">
    ````jsx
    import { Button } from 'lambshock';
    
    export default function Example() {
      return <Button>Click Me</Button>;
    }
    ````
  </Step>
</Steps>
